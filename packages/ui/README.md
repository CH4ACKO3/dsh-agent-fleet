# UI

当前在 DSH Web 新会话的“标准模式”右侧提供“组建团队”下拉入口，可选择配置模式或交互模式。

配置模式收集团队名称与长期定位、成员身份与职责、成员级模型路由、默认频道、长期工作方式、
共享资源引用，以及用户侧的信息密度和通知偏好；后两项可在运行时继续修改。团队不在这里绑定一次性任务；
工作在团队建立后单独提交。团队工作区直接继承新会话中原生工作区组件的选择，本面板不维护第二份工作区状态。
固定的 Fleet 协调 Agent 由运行端自动加入，不作为用户需要配置的团队成员。

界面文案优先跟随 DSH Web 根节点的 `lang`。字段预设名称与正文按中英文双语保存；“导入模板或预设库”
既接受完整 Team 模板，也接受带 `fields` 的字段预设目录。导入同 ID 或同名称条目时会更新其双语内容，
同时保留现有本地 ID，避免已经选用该预设的配置失去引用。

成员以可拖动排序的工牌卡片展示，卡面显示持久姓名和角色，并使用与成员绑定、可编辑的低饱和配色。
新成员会通过 Core 的共享身份逻辑获得一个可编辑的随机英文名与受控随机配色；编辑器同时提供
12 个推荐色和原生颜色选择器，允许保存任意 `#RRGGBB` 颜色。
正式成员和预设成员使用相同尺寸，预设卡可以直接拖入成员区并按落点加入，成员卡拖回预设区时经确认后移除。
点击成员卡片、虚线添加卡或预设卡后，在独立悬浮窗中编辑成员详情与模型路由。
