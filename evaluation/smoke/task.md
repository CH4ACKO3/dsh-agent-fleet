# 评测任务

在工作区实现一个不依赖第三方库的 Python 3 命令行程序 `word_stats.py`。

程序接收一个 UTF-8 文本文件路径，向标准输出写入一行 JSON，字段为：

- `lines`：按 `splitlines()` 定义的行数；
- `words`：按连续非空白字符片段统计的词数；
- `characters`：Python 字符串长度，不按 UTF-8 字节数计算。

要求：

1. 缺少参数或文件无法读取时，以非零状态退出并向标准错误输出简明原因。
2. 提供自动化测试，至少覆盖 ASCII、多行中文、空文件和文件不存在。
3. 实际运行测试并记录结果。
4. 把实现、测试和一份简短的验证报告作为团队共享文件公开。
5. 最终 result Task 必须说明产物路径、测试命令和真实结果。
