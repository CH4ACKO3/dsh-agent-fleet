# Matilda 16×16 瓷砖问题

## 题目

考虑一个 16×16 的单位正方形网格。Matilda 想在网格上放置一些矩形瓷砖，瓷砖可以有不同大小，满足每条边都在网格线上，且每个单位正方形最多被一块瓷砖覆盖。

求：使每行和每列都恰好有一个单位正方形不被覆盖时，Matilda 最少需要放置多少块瓷砖？
